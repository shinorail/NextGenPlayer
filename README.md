# NextGen Media Player

![Version](https://img.shields.io/badge/version-1.0.0-orange.svg)
![Developer](https://img.shields.io/badge/Developer-篠ノ井乗務区制作-blue.svg)

**NextGen Media Player** は、シンプルながらも高機能を備えた、篠ノ井乗務区制作（Shinonoi Crew Depot Works）による次世代メディアプレーヤーです。

## 🚉 特徴
- **多言語対応**: 日本語と英語をワンクリックで切り替え可能。
- **柔軟な再生**: 0.5xから3.0xまでの倍速再生、10秒戻る/30秒進むなどの直感的な操作。
- **画質調整**: 動画の輝度（明るさ）をスライダーでリアルタイムに変更可能。
- **記録機能**: ワンボタンで高画質なスクリーンショットを撮影・保存。
- **簡単操作**: 動画ファイルをウィンドウにドラッグ＆ドロップするだけですぐに再生。

## 🚀 インストール方法
1. [Releases](https://github.com/shinorail/NextGenPlayer/releases/latest) ページにアクセスします。
2. `NextGen Media Player Setup 1.0.0.exe` をダウンロードします。
3. ダウンロードしたファイルを実行し、指示に従ってインストールしてください。

## 🛠 動作環境
- OS: Windows 10 / 11
- 対応フォーマット: .mp4, .mkv, .avi, .webm, .mov

## 📖 使い方
- **再生/一時停止**: スペースキー または ボタンをクリック
- **スクリーンショット**: 「📸 スクショ」ボタンをクリックして保存先を選択
- **動画の追加**: フォルダから直接ドロップするか、「📂 開く」から選択
